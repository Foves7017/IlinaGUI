在 `global` 中包括了各种管理器的 `get` 方法，以及各种路径，在下面列出可用的路径。
 - `workspace_path() -> Path`：返回当前工作目录的绝对路径。
 - `app_path() -> Path`：返回应用安装的根目录。
 - `python_runtime_path() -> Path`：返回应用所使用的 Python 的路径。
 - `plugin_path() -> Path`：返回插件目录（`app_path()/'plugins'`）的简写。
 - `config_path() -> Path`：返回配置目录（`app_path()/'configs'`）的简写。
 - `APP_CONFIG_PATH` 和 `AppConfig`：保存一些应用全局的设置，具体包括：
	 - `default_workspace (str)`：默认的工作目录
	 - `latest_workspace (str|None)`：上次打开的工作目录
	 - `light_theme_name (str)`：设置的亮色模式主题名称
	 - `dark_theme_name (str)`：设置的暗色模式主题名称
