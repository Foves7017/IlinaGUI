# 初始化参数
无
# 属性

| 属性名     | 类型           | 读写 | 说明                                          |
| ------- | ------------ | -- | ------------------------------------------- |
| `text`  | `str`        | 读写 | 输入文本框的 Markdown 内容                          |
| `state` | `InputState` | 读写 | 输入框的状态，`SEND` 表示按钮显示为发送（↑），`STOP` 表示按钮显示为停止（■） |
# 信号

| 信号名    | 参数  | 说明                             |
| ------ | --- | ------------------------------ |
| `send` | 无   | 用户按下发送（Enter，不含 Shift，或点击发送按钮） |
