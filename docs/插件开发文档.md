# Ilina GUI 插件开发文档

当前版本：v0.0.1

插件由 Python 程序编写。
一个插件应该是一个 Python 包，可以被导入。
应该至少包括以下属性：

1. `ContentWidget: QWidget|QQuickWidget` 这是插件的主体，会被创建并显示到屏幕上。在创建时，会传入 `plugins.consts.InitParam`。
2. `PLUGIN_DISPLAY_NAME: str` 这是在 Dock 标题栏显示的名称
3. `CONNECTED_FILES: str|list[str]` 指定了和插件关联的扩展名，关联了扩展名的文件会在文件管理器中显示，双击时会创建插件的 widget
4. `ACTIVE_BAR_ICON_CHARA: str` 指定一个 Fluent System Icons 中的字符。会显示在活动栏


plugins.consts.InitParam 的内容：
1. `workspace: str`: 当前的工作区
2. `open_file: str|None`：文件管理器中双击打开的文件名，如果是其他方法创建则默认为 None
3. `formatter: Formatter`：主题管理器，可用于兼容主题
4. `plugin_manager: PluginManager`: 插件管理器，可用于获得各种信息
5. `uuid: UUID`: 创建的 Dock 的 UUID
