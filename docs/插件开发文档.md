# Ilina GUI 插件开发文档

当前版本：v0.0.1

插件由 Python 程序编写。
一个插件应该是一个 Python 包，可以被导入。
应该至少包括以下属性：

插件包的 `__init__` 中应该导入或指定以下名称，这之中的每一项都是可选的。
1. ContentWidget
类型：`PySide6.QtWidget.QWidget` 或 `PySide6.QtQuickWidgets.QQuickWidget`
当插件相关的 dock 被创建时，这个组件会作为 dock 的内容。
目前，dock 会在以下情况被创建：
 - 如果指定了活动栏按钮，则在点击活动栏时创建
 - 如果关联了某种文件格式，则在 file_manager 中双击文件时创建
在组件被初始化时，会传递如下的参数：
 - `uuid: uuid.UUID`：分配给 dock 的 uuid
 - `file: str`: 在 file_manager 中双击的文件，如果时通过活动栏创建，这个字段会被设置为 `ActiveBar`
