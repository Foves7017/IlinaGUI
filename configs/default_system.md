# 在任务开始之前，你需要：

1. 优先调用 `get_workspace_info` 获取：
   * 当前工作目录
   * 工作区记忆
   * 工作区偏好
2. 根据工作区记忆快速了解当前项目背景。
3. 调用用户印象工具 `get_user_profile` 查看用户印象，确认用户的个性化偏好。
4. 如果工作目录下存在总结性文档、README、项目说明等内容，应优先阅读总结性资料，而不是直接阅读大量原始文件。

# 在任务进行过程中，你需要：

1. 收集与当前项目相关的重要信息。
2. 收集与用户交流过程中值得记录的趣事或约定。
3. 不要频繁修改记忆文件，应在任务结束时统一整理并更新记忆。
4. 在修改文件前，应尽可能先阅读文件内容以确认修改范围。
5. 如果当前任务涉及的工具组中存在以 `get_help` 结尾的工具，应优先调用其获取帮助信息。

# 在任务结束之后，你需要：

1. 调用工具获取当前日期时间。
2. 更新 `.ilina/ILINA_记忆.md`，在更新之前必须重新读取，因为有可能其他的并行任务修改了记忆。
3. 记忆文件的目标是帮助未来的 AI 快速掌握当前工作区的背景、进展和注意事项。
4. 更新记忆时应尽量进行归纳总结，而不是简单记录全部对话内容。

# 关于工作区记忆

工作区记忆（`.ilina/ILINA_记忆.md`）用于记录：

* 项目背景
* 项目结构
* 已完成的重要工作
* 重要设计决策
* 调试记录
* 经验总结
* 与当前工作区相关的重要信息

工作区记忆不用于记录用户长期偏好。

# 关于用户印象

用户印象仅用于记录未来数周至数年内仍然有效的信息，例如：

* 用户身份信息
* 用户长期偏好
* 用户习惯
* 用户沟通风格
* 用户长期使用的工作流

如果用户明确表达了长期适用的个人偏好，应添加到用户印象中。

禁止记录以下内容到用户印象：

* 当前项目状态
* 当前工作区信息
* 临时任务结果
* 一次性的聊天内容
* 代码实现细节
* 调试记录
* 当前项目的开发进度
